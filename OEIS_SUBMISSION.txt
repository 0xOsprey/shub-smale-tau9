# OEIS Submission Draft for z_max(tau) (Shub-Smale tau-Conjecture)
# Submit at: https://oeis.org/Submit.html

%N Maximum number of distinct integer roots of a nonzero univariate polynomial in Z[x] computable by a constant-free straight-line program (SLP) of length at most n.
%S 1,2,3,3,4,5,5,6,6,7
%O 1,2
%C A constant-free straight-line program (SLP) of length n starts from g_{-1} = 1 and g_0 = x, and for k = 1..n computes g_k = g_i op g_j with op in {+, -, *} and -1 <= i, j < k.
%C a(n) is the maximum number of distinct integer roots of any nonzero polynomial f in Z[x] computable in at most n gates.
%C The Shub-Smale tau-conjecture (Smale's 4th Problem) asks whether a(n) is bounded above by a polynomial in n; an affirmative answer implies P_C != NP_C in the Blum-Shub-Smale model.
%C Exact values for n = 1..8 were established by Felipe Santibanez-Leal (August 2026), who also established a(10) >= 7 and ruled out 9-gate SLPs ending in a multiplication gate.
%C Exact value a(9) = 6 (59,308,136,697 candidate 9-gate leaves, a superset of all canonical 9-gate SLPs) and a(10) = 7 (2,675,837,421,376 candidate 10-gate leaves) were established unconditionally over all of Z via exact-CRT certification across all lengths <= n, python-flint / Python Z[x] verification, and Lean 4 soundness proofs in November 2026, proving that the minimum length for 7 distinct integer roots is 10 and for 8 distinct integer roots is 11.
%C Known lower bounds for n >= 11 (all machine-verified in Lean 4): a(11) >= 8, a(12) >= 9, a(13) >= 10, a(14) >= 10, a(15) >= 11, a(16) >= 12, a(17) >= 13, a(18) >= 14.
%C Asymptotically, a(3*k) >= 2*k for all k >= 1 via pronic folding prod_{j=0}^{k-1} (x*(x-1) - j*(j+1)).
%e a(1) = 1: x - 1 (root 1).
%e a(2) = 2: x*(x - 1) (roots 0, 1).
%e a(3) = 3: x*(x^2 - 1) (roots -1, 0, 1).
%e a(5) = 4: q*(q - 2) where q = x^2 - x (roots -1, 0, 1, 2).
%e a(6) = 5: x*(x^2 - (2 - x^2)^2) = -x*(x^2 - 1)*(x^2 - 4) (roots -2, -1, 0, 1, 2).
%e a(8) = 6: q*(q - 2)*(q - 6) where q = x^2 - x (roots -2, -1, 0, 1, 2, 3).
%e a(9) = 6: exhaustive exact-CRT certification over all 59,308,136,697 candidate 9-gate leaves (and all shorter lengths <= 8) finds no nonzero polynomial with >= 7 distinct integer roots in Z.
%e a(10) = 7: -x*(x^2 - 1)*(x^2 - 4)*(x^2 - 9) (roots -3..3); exhaustive exact-CRT certification over all 2,675,837,421,376 candidate 10-gate leaves (and all shorter lengths <= 9) finds 19 per-item deduplicated seven-root survivor records and 0 with >= 8 distinct integer roots in Z.
